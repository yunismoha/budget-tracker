# My Budget Tracker

## Project Overview

My Budget Tracker is a simple web application designed to help users record and organize their daily expenses.

The project was developed using HTML and CSS. It focuses on creating a clean, user-friendly interface with organized sections and a consistent visual design.

## Technologies Used

- HTML5 – Used to structure the web application.
- CSS3 – Used to style the application and improve its appearance.
- Google Fonts – Used to improve typography.
- YouTube Embed – Used to display budgeting educational content.

## Project Features

### 1. Main Header
Displays the application name, logo, and a short description.

### 2. Add Expense Form
Allows users to enter:
- Expense name
- Expense amount
- Expense category
- Expense date

The form includes a dropdown with Food, Transport, Rent, Entertainment, and Other categories.

### 3. Expense Table
Displays sample expenses in an organized table with four columns:
- Name
- Amount
- Category
- Date

### 4. Instructions Section
Uses HTML details and summary elements to provide collapsible instructions on how to use the tracker.

### 5. Budgeting Video
Includes an embedded YouTube video containing budgeting tips.

## Design and Styling

The application uses a consistent purple, lavender, and white color palette.

- Purple: Main headings, buttons, and table headers.
- Lavender: Alternating table rows and highlighted elements.
- White: Content cards and form backgrounds.
- Light grey: Main page background.

### Typography

- Poppins: Used for headings.
- DM Sans: Used for body text, forms, and table content.

### CSS Techniques

The project uses:
- CSS variables.
- Flexibility and responsive styling.
- CSS box model (margin, padding, border, and border-radius).
- Hover effects.
- Focus states.
- Advanced CSS selectors.
- Media queries.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the Budget Tracker interface.

## Current Limitations

The application currently displays hardcoded sample expenses. Adding, editing, and deleting expenses will be implemented in future development stages using JavaScript.
